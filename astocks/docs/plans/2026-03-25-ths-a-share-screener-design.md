# 同花顺 A 股选股功能设计

## 背景

目标是在同花顺指标/选股公式编辑器中实现一套 A 股股票筛选逻辑，满足以下业务条件：

1. 近 15 天内有倍量突破
2. `1 > 大单净量 > 0`
3. `散户数量 < 0`
4. 多头排列
5. 至少 2 天突破前一天高点

其中条件 2 和 3 依赖同花顺 `Level-2` 相关指标。

## 设计目标

- 先提供一版不依赖 `Level-2` 的基础选股公式，确保可立即运行。
- 再提供一版包含 `Level-2` 条件占位的完整版，便于后续替换真实字段名。
- 条件拆分为中间变量，便于在同花顺选股器中逐步验证和排查。

## 已确认口径

### 多头排列

默认采用：

```text
MA(C,5) > MA(C,10) > MA(C,20) > MA(C,60)
```

### 倍量突破

采用以下定义：

- 当天收盘价突破前一天高点
- 当天成交量至少为前一天成交量的 2 倍

对应逻辑：

```text
C > REF(H,1) AND VOL >= 2 * REF(VOL,1)
```

## 方案比较

### 方案 1：基础版 + 完整版两套公式

- 基础版只使用日线行情字段
- 完整版在基础版之上增加 `Level-2` 条件

优点：

- 可以立即落地运行
- `Level-2` 字段名未确认时不阻塞整体交付
- 便于后续替换和调试

缺点：

- 需要维护两套公式文本

### 方案 2：单一公式 + L2 开关

- 在一套公式中将 `Level-2` 条件做成开关

优点：

- 只有一套公式

缺点：

- 同花顺公式环境对这种写法未必友好
- 可读性和排错体验较差

### 方案 3：指标公式 + 选股公式拆分

- 一个公式输出各条件信号
- 一个公式负责最终选股

优点：

- 便于观察各条件命中情况

缺点：

- 使用步骤更复杂
- 跨公式引用在不同环境下兼容性不稳定

## 选型结论

采用方案 1：提供基础版和完整版两套选股公式。

## 条件拆解

### 基础版条件

基础版只实现条件 1、4、5。

#### 条件 A：当日突破前一天高点

```text
BREAK1 := C > REF(H,1);
```

说明：

- 使用收盘价突破前一天最高价作为突破判定

#### 条件 B：倍量突破

```text
DOUBLEVOL_BREAK := BREAK1 AND VOL >= 2 * REF(VOL,1);
```

说明：

- 同时满足突破和倍量

#### 条件 C：近 15 天内至少出现一次倍量突破

```text
HAS_DOUBLEVOL_15 := COUNT(DOUBLEVOL_BREAK,15) >= 1;
```

说明：

- 满足“近 15 天内有倍量突破”

#### 条件 D：多头排列

```text
BULL_ALIGN := MA(C,5) > MA(C,10)
    AND MA(C,10) > MA(C,20)
    AND MA(C,20) > MA(C,60);
```

说明：

- 均线采用 `5/10/20/60`

#### 条件 E：近 15 天内至少 2 天突破前一天高点

```text
BREAK_COUNT_15 := COUNT(BREAK1,15) >= 2;
```

说明：

- 与条件 1 保持一致，观察窗口同样使用 15 个交易日

### 基础版最终输出

```text
HAS_DOUBLEVOL_15 AND BULL_ALIGN AND BREAK_COUNT_15;
```

## 完整版条件

完整版在基础版上增加条件 2、3。

### 条件 F：大单净量在 0 到 1 之间

字段名暂未确认，先使用占位名：

```text
BIG_NET_OK := L2_BIGORDER_NET > 0 AND L2_BIGORDER_NET < 1;
```

### 条件 G：散户数量小于 0

字段名暂未确认，先使用占位名：

```text
RETAIL_OK := L2_RETAIL < 0;
```

### 完整版最终输出

```text
HAS_DOUBLEVOL_15 AND BULL_ALIGN AND BREAK_COUNT_15
AND BIG_NET_OK AND RETAIL_OK;
```

## Level-2 接口约定

由于用户尚未确认同花顺当前环境中 `Level-2` 相关指标的真实字段名，设计中采用以下占位字段：

- `L2_BIGORDER_NET`
- `L2_RETAIL`

后续只需将这两个占位字段替换为同花顺公式编辑器中的真实指标表达式即可，无需改动其余筛选逻辑。

## 验证方案

建议按以下顺序逐步验证，避免多个条件叠加后难以判断筛除原因：

1. 单独验证 `BREAK1`
2. 单独验证 `DOUBLEVOL_BREAK`
3. 验证 `HAS_DOUBLEVOL_15`
4. 叠加 `BREAK_COUNT_15`
5. 叠加 `BULL_ALIGN`
6. 最后叠加 `BIG_NET_OK` 与 `RETAIL_OK`

## 风险与限制

- 当前唯一未确定项是同花顺 `Level-2` 公式环境中的真实字段名。
- 如果同花顺版本不支持直接引用某些 `Level-2` 指标，则完整版需要改为引用用户自建的指标公式结果。
- 当前“近 15 天内有倍量突破”和“至少 2 天突破前一天高点”共用 15 天窗口，这是有意保持条件口径一致的设计。

## 交付物

本设计最终对应两类可交付内容：

1. 基础版同花顺选股公式
2. 含 `Level-2` 占位字段的完整版选股公式
